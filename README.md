# mudulo9EBAC
O trabalho consistiu em carregar o dataset SINASC-RO 2019, aplicar técnicas de agrupamento e agregação (groupby e mean/agg) para calcular estatísticas de idade, peso e número de nascimentos por critérios (município, mês, escolaridade), e, por fim, extrair um insight sobre a relação entre a escolaridade da mãe e a idade na maternidade.
